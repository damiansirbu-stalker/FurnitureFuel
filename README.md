# Hideout Furniture Infinite Fuel: No Fuel Consumption for Placeable Lights

Removes fuel and battery consumption from all placeable light furniture. Lights no longer require batteries, kerosene, or gauss ammo to operate. All visual effects, sounds, flickering, and toggle behavior are preserved.

[Releases](https://github.com/damiansirbu-stalker/Hideout-Furniture-Infinite-Fuel/releases)

Requires: Anomaly 1.5.3, Modded exes, [xlibs](https://www.moddb.com/mods/stalker-anomaly/addons/xlibs-1001), Hideout Furniture by Aoldri
